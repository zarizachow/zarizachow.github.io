# Zariza Chowdhury portfolio

Files: index.html (main page), resume.html (resume viewer), style.css (look), script.js (menu and popups).

## Files you add yourself
- assets/images/profile.jpg : your photo (square, about 600 x 600 px)
- documents/CV.pdf : your resume
- assets/images/diploma-masters.jpg and diploma-bachelors.jpg : diploma photos (landscape JPG, about 1200 px wide)
- documents/transcript-masters.pdf and transcript-bachelors.pdf : transcripts
To replace any of these on GitHub, open the folder, Add file > Upload files, and upload a file with the same name.

## Edit later
Open a file on GitHub, click the pencil icon, edit, then Commit changes.
- New job or project: copy a whole <article class="card" id="..."> block, give it a new unique id, and change the text. The part inside <div class="more"> is what shows in the popup.
- Link from one card to another: <a href="#id" data-open="id">Text</a>
- New event: copy a whole <article class="entry"> block in the Corporate Events section.
