Commercial & Pricing Analytics · Predictive Analytics

Competitor Pricing Database and Churn Prediction

MSc Capstone with Magenta Telekom, second largest telecom operator in Austria · Vienna · Mar – Jun 2026

Business problem
Magenta wanted a clearer view of how its prices compare with competitors, and whether price gaps affect customer churn.
Approach
Collected competitor prices from public websites using AI-assisted scraping and built a query-ready database for repeatable analysis. Built an interactive dashboard comparing pricing trends by operator and product tier. Built an experimental linear regression model to test whether competitor price gaps affected next month's churn.
Outcome
Identified positioning gaps across the Austrian market. Documented the process so Magenta's analytics team can add the new variables to their existing churn model. The regression model was experimental.
Tools
Python (Jupyter Notebook), Excel, AI-assisted web scraping, linear regression, Tableau
